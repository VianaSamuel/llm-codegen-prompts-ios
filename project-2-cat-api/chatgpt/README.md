# CatAPI - ChatGPT

Este repositório contém o aplicativo CatAPI gerado utilizando ChatGPT como parte do trabalho de conclusão de curso (TCC).

## 1. App Inicial

### a) Prompt Utilizado:

Você é um especialista em desenvolvimento iOS. Crie um prompt que possa ser usado para gerar um aplicativo iOS em Swift que consuma dados da API pública The Cat API (https://thecatapi.com/), exibindo imagens e informações relacionadas a gatos. O prompt deve instruir o modelo a produzir código funcional, legível e organizado, seguindo boas práticas de programação em Swift e com arquitetura facilmente adaptável. Mantenha todo o prompt em uma única linha contínua, sem quebras de linha, e inclua todas as instruções necessárias para gerar o aplicativo corretamente.

### b) Prompt Gerado:

Crie um aplicativo iOS completo em Swift que consuma dados da API pública The Cat API (https://thecatapi.com/), exibindo imagens de gatos e informações relacionadas a cada imagem, produzindo código funcional, legível e organizado, seguindo boas práticas de programação em Swift, utilizando arquitetura modular e facilmente adaptável, separando claramente modelos de dados, view models, serviços de rede e views, implementando requisições assíncronas à API com tratamento de erros, cache básico de imagens para melhor desempenho, atualização dinâmica da interface ao receber os dados, interface intuitiva construída em SwiftUI ou UIKit, comentários claros explicando cada parte principal do código, e garantindo que o aplicativo funcione corretamente ao ser compilado, sem dependência de bibliotecas externas, mas estruturado para futura expansão de funcionalidades.

## 2. App Após Modificações

### a) Prompt Utilizado:

Você é um especialista em desenvolvimento iOS. Crie um prompt que possa ser usado para modificar um aplicativo iOS previamente gerado que consome dados da The Cat API (https://thecatapi.com/). O prompt deve instruir o modelo a alterar a arquitetura do projeto de MVVM para VIPER, mantendo a consistência, funcionalidade e clareza do código existente, sem alterar a lógica de negócios nem os dados da API. Mantenha todo o prompt em uma única linha contínua, sem quebras de linha, e inclua todas as instruções necessárias para gerar o aplicativo corretamente.

### b) Prompt Gerado:

Crie uma versão modificada de um aplicativo iOS previamente gerado em Swift que consome dados da The Cat API (https://thecatapi.com/), alterando a arquitetura do projeto de MVVM para VIPER, mantendo toda a funcionalidade, consistência e clareza do código existente, sem alterar a lógica de negócios nem os dados da API, organizando o código em módulos VIPER completos com View, Interactor, Presenter, Entity e Router, garantindo que cada camada tenha responsabilidades bem definidas, preservando a separação de preocupações, atualizando a interface dinamicamente conforme os dados são carregados, mantendo tratamento de erros, cache de imagens e requisições assíncronas, comentando claramente as partes principais do código, e assegurando que o aplicativo continue funcionando corretamente ao ser compilado, estruturado de forma que futuras expansões sejam fáceis de integrar.
